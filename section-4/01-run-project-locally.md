# Run the project Locally Using Docker compose

- Docker compose is used to run the project locally in the EC2.

- In this lecture we will use the `docker compose` which is installed as part of `docker`.

<img width="1071" height="400" alt="image" src="https://github.com/user-attachments/assets/86b5fcea-3ff4-4cd9-8e12-462dd09703b7" />


- Just go to the directory of cloned repo and run `docker compose up -d`.

- Make sure before running docker compose, increase the volume size to 30 GB . otherwise you will face storage issue.
